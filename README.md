# คลังแล็บ

เว็บรวมแล็บและเกมสำหรับสอน ใช้เฉพาะอาจารย์ จัดแล็บตามรายวิชา Hydraulics, Statics, Highway และ Survey

## เปิดดู

เปิดโฟลเดอร์นี้ใน VS Code แล้วเลือกวิธีใดก็ได้

- ติดตั้งส่วนเสริม Live Server แล้วคลิกขวาที่ `index.html` เลือก **Open with Live Server** (แนะนำ)
- ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์

ต้องต่ออินเทอร์เน็ต เพราะฟอนต์และตัวอ่าน ZIP (JSZip 3.10.1) โหลดจาก CDN

## โครงสร้างไฟล์

```text
index.html           โครงหน้าเว็บ
css/style.css        หน้าตาทั้งหมด สีอยู่ใน :root
js/app.js            การทำงานทั้งหมด
js/sample-data.js    cop-lab.zip แบบ base64 สำหรับปุ่มไฟล์ตัวอย่าง
samples/cop-lab.zip  ไฟล์ตัวอย่างสำหรับให้เพื่อนใช้เป็นแบบ
```

จุดที่แก้บ่อยใน `js/app.js`

| ต้องการแก้ | ค้นหา |
|---|---|
| รายวิชา | `var SUBJECTS` |
| ไอคอนรายวิชา | `var ICONS` |
| รายการตรวจก่อนส่ง | `var HUMAN_CHECKS` |
| ไฟล์ต้องห้ามและเพดานขนาด | `var BLOCKED`, `MAX_ZIP` |
| กติกาตรวจไฟล์ | `function runChecks` |
| การล็อกอิน | `function viewLogin` |
| การบันทึกแล็บ | `function publish` |

## สิ่งที่ทำได้แล้ว

- ล็อกอินด้วยอีเมลและรหัสผ่าน
- ดูรายวิชา ค้นหาแล็บ และดูหน้า “ผู้ลงแล็บ”
- ส่งแล็บเป็น `.html` หรือ `.zip` พร้อมตรวจไฟล์และให้ผู้ดูแลอนุมัติ
- เปิดแล็บใน sandboxed iframe และใช้โหมดสอนหน้าห้อง
- เจ้าของอีเมลที่ลงแล็บเท่านั้นที่เห็นปุ่มแก้ไข ถ้าเปลี่ยนไฟล์ต้องตรวจใหม่

## สิ่งที่ยังเป็นการจำลอง

ตอนนี้ทุกอย่างอยู่ในหน่วยความจำของเบราว์เซอร์ **รีเฟรชแล้วหาย** และยังไม่ปลอดภัยพอใช้จริง

- บัญชีและรหัสผ่านอยู่ในตัวแปร `ACCOUNTS`
- แล็บอยู่ในตัวแปร `LABS` และไฟล์แล็บอยู่ในฟิลด์ `srcdoc`
- การตรวจเจ้าของแล็บอยู่ฝั่งเบราว์เซอร์
- ขั้นผู้ดูแลตรวจยังเป็นขั้นตอนต่อจากผู้ส่งในหน้าเดียวกัน ยังไม่แยกสิทธิ์ผู้ดูแล

## ขั้นต่อไปสำหรับใช้งานจริง

แผนที่คุยไว้คือใช้ Supabase

1. **บัญชี:** ใช้ Supabase Auth แบบอีเมลและรหัสผ่าน ปิดการสมัครเอง ให้ผู้ดูแลเพิ่มอีเมลอาจารย์ และมีลิงก์ลืมรหัสผ่าน
2. **ข้อมูล:** สร้างตาราง `labs` และ `profiles` ตั้ง Row Level Security ให้อ่านได้เฉพาะคนที่ล็อกอิน และแก้ได้เฉพาะ `owner_id` ของแถวนั้น
3. **ไฟล์แล็บ:** เก็บใน private bucket และเปิดด้วย signed URL
4. **ผู้ดูแล:** เพิ่มบทบาท admin และสถานะ `pending`, `approved`, `rejected` อนุมัติได้เฉพาะ admin
5. **ขึ้นเว็บ:** เก็บโค้ดใน GitHub repo แบบ private แล้ว deploy ด้วย Cloudflare Pages

รหัสผ่านต้องให้ Supabase Auth จัดการเท่านั้น ห้ามเก็บเองในตารางหรือในโค้ด และห้ามใส่ `service_role` key ไว้ในไฟล์ฝั่งเบราว์เซอร์

## ข้อมูลของแล็บหนึ่งรายการ

```js
{
  id, ownerEmail, s /* รหัสวิชา */, title, desc, date, dateText,
  srcdoc /* เนื้อหาแล็บ */, author, duration, chapter, q /* คำถาม */, a /* เฉลย */
}
```
